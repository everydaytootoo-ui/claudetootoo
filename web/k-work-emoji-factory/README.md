# 직장인 이모지 팩토리 (K-WorkEmoji.xlsx)

Microsoft Excel 스프레드시트 테마로 만든 한국 직장인용 이모지/짤 복사·다운로드 및 텍스트 이모지 생성 웹앱 프로토타입입니다.

빌드 없이 동작하는 단일 정적 HTML 파일(`index.html`)로, Tailwind CSS(CDN)와 순수 JavaScript(Vanilla JS)로 구현했습니다.

## 실행 방법

브라우저에서 `index.html`을 바로 열거나, 정적 서버로 서빙하세요.

```bash
cd web/k-work-emoji-factory
python3 -m http.server 8080
# http://localhost:8080 접속
```

## 주요 기능

- **엑셀 스프레드시트 테마**: 초록색(#107C41) 리본 헤더, 열(A/B/C…)·행(1/2/3…) 번호가 있는 셀 격자, `fx` 수식 입력줄 스타일 검색창, 화면 하단 시트 탭으로 구현한 카테고리 내비게이션.
- **카테고리 필터 + 검색**: 전체/인기, 넵/확인, 퇴근/연차, 멘탈바사삭, 점심/휴식, 이모지 생성기. 키워드 검색과 한글 초성 검색(예: `ㅌㄱ` → 퇴근) 지원.
- **메신저별 규격 다운로드/복사**: 이모지 셀 클릭 시 모달에서 Slack(128px) / Teams(256px) / 카톡(500px) PNG 다운로드와 `navigator.clipboard.write` 기반 클립보드 이미지 복사(성공 시 토스트 알림) 제공. 이모지는 Canvas에 실시간으로 래스터라이즈합니다.
- **텍스트 이모지 생성기**: 네온/도장/역동적(움직이는 느낌)/픽셀 4가지 스타일. 텍스트·색상 입력에 따라 Canvas 미리보기가 실시간으로 갱신되고, 동일한 3가지 메신저 규격으로 즉시 다운로드/복사할 수 있습니다.
- **보스키(Boss Key)**: `ESC` 키 또는 헤더의 "보스키" 버튼으로 가짜 엑셀 스프레드시트 화면으로 즉시 전환. 위장 화면의 `Sheet1` 탭을 클릭하거나 `ESC`를 다시 누르면 복귀합니다.
- **다크모드 / 라이트모드**: 헤더의 토글 버튼으로 전환하며 `localStorage`에 저장됩니다.
- **광고 배너 자리**: 헤더 아래 728×90, 사이드바 300×250 위치에 AdSense 삽입용 placeholder `div`를 배치했습니다. 실제 배포 시 해당 위치에 AdSense 스니펫을 넣으면 됩니다.
- **SEO / 바이럴**: Open Graph·Twitter Card 메타 태그, "오늘의 칼퇴 확률 테스트" 미니 위젯, 카카오톡 공유 버튼(Web Share API 우선 사용, 미지원 브라우저는 링크 클립보드 복사로 대체 — 실서비스에서는 Kakao SDK로 교체 가능한 주석 포함).

## 참고

- 이모지는 이미지 파일 없이 시스템 폰트의 유니코드 글리프를 Canvas에 그려 사용하므로 별도 이미지 에셋이 필요 없습니다. 실제 서비스에서는 커스텀 짤 이미지(움짤 GIF 포함)로 교체할 수 있도록 `EMOJI_DATA` 배열의 각 항목에 이미지 URL 필드를 추가하는 구조로 쉽게 확장 가능합니다.
- `og:image`, `og:url`은 배포 도메인/이미지 경로로 교체가 필요합니다.
- Kakao 공유 버튼을 실제 카카오톡 공유로 동작시키려면 [Kakao SDK](https://developers.kakao.com/docs/latest/ko/message/js-link)를 로드하고 JavaScript 키로 초기화한 뒤 코드 내 주석 처리된 `Kaka.Share.sendDefault(...)` 부분을 활성화하세요.
